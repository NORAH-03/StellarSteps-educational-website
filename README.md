# 🌌 StellarSteps

An interactive educational website designed to help children explore the solar system through engaging content, interactive activities, and games.

## 📌 About the Project

StellarSteps is a web-based educational platform developed as part of a **Web Engineering and Development** course project.

The website introduces children to planets and space through simple explanations, visual content, and interactive activities. The project focuses on combining education and entertainment to make learning about the solar system more engaging.

## ✨ Features

* 🌍 Information pages for the planets
* 🌙 Moon phases information
* 🎮 Interactive educational games
* 🪐 Visual exploration of the solar system
* 📚 Educational content designed for children
* 🧭 Multiple pages with simple navigation

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* PHP
* Visual Studio Code

## 🎯 Project Objective

The goal of StellarSteps is to provide a simple and engaging way for children to learn about space while interacting with educational content and activities.

## 👩‍💻 Project Type

**Course Project — Web Engineering and Development**
